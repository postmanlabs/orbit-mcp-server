# Contributing

The MCP server implementation in this repository is synced from Postman's internal
[`postman-eng/orbit-mcp-server`](https://github.com/postman-eng/orbit-mcp-server)
repository. Pull requests that change files under `src/` or `test/` cannot be merged
here directly — open an issue.

Documentation, CI, and repository tooling changes are welcome via pull request in
this repository.

## Reporting issues

- [Bug report](https://github.com/postmanlabs/orbit-mcp-server/issues/new)
- [Feature request](https://github.com/postmanlabs/orbit-mcp-server/issues/new)
